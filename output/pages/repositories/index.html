Learning log

  • Teaching repositories work best when each unit has a reproducible notebook and a short README with expected outcomes.
  • Slide repositories are easier to maintain when they include a single source of truth for assets and bibliography.
  • Research code is more reusable when notebooks are paired with lightweight scripts for data preparation and plotting.
  • Forked repositories are useful for prototyping, but production teaching/research material should move to independent repositories with focused documentation.
